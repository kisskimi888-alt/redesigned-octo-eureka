# 家庭护理上门调度与共享用工决策台

对照同一批预约在三种模式下的可行排程，找出共享班次能补上的具体订单和增量费用。页面实际运行 Notebook 的规则插单、CP-SAT 和独立排程检查器。算法对照按需运行纯 WOA、纯 PSO 和 WOA-PSO。

## 在 Windows 本地启动

解压后进入包含 `app.py` 的目录。用 Python 3.12 打开终端，依次执行：

```powershell
py -3.12 -m pip install -r requirements.txt
py -3.12 -m streamlit run app.py
```

终端会显示浏览器地址。数据已内嵌，安装依赖后可离线运行。

## 90 秒演示

1. 保持默认 **共享补缺** 情景，查看 B、C 的覆盖、准时和费用对照。默认预算 80 元。
2. 初版 C 启用 S01，覆盖从 15/16 到 16/16，较 B 增加 57.50 元。甘特图显示 S01 负责 J11、J16，J03 则由 F04 接手。
3. 点击 **撤销 S01 并重排**。新版本变为 15/16，展开差异可见 J11 换人、J03 转为未安排，以及其他变化。
4. 选中方案，点 **确认当前工作单**，下载该版本的 CSV。CSV 使用 UTF-8 BOM，含全部 16 单。
5. 如需讲算法，展开 **算法对照** 并运行。它使用当前 C 的输入与三个相同随机种子，逐项比较覆盖、迟到和费用。

## 口径与来源

基于《基于资源共享模式探索下家庭医疗护理中心 H 的 IE 改善作品报告》的 16 客户、4 名全职及 4 个候选共享班次结构。与 `Homecare_Shared_Shift_WOA_PSO.ipynb` 使用同一套演示数据。时窗、服务分钟、路网和费用均为仿真假设。主指标为全订单覆盖和准时开工，费用包括交通、加班和借调。预算只约束借调费。工作单中的到达时间是按直接前往估算的计划时间。

`scheduler.py` 包含数据、规则插单、求解和独立校验，`app.py` 负责界面、状态和导出。方案名称区分已证明最优、可行和回退状态。单次操作及确认记录保存在当前页面会话内。
